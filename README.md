# Noor Ahmad Faiz Khan, portfolio

Static multi-page site (Home, About, Research, Projects, Contact). Plain HTML, CSS and JavaScript, no build step.

## Publish on GitHub Pages
1. Create a repository (for a user site, name it `noor-faiz.github.io`).
2. Upload everything in this folder to the repository root.
3. Settings, Pages, Deploy from branch, `main`, `/ (root)`.

## Edit content
- Papers, projects, skills, ResearchGate link: `data.js` (add each published paper URL in its `link:""` field to show a Read paper button)
- Page text: the `.html` files
- Colors and fonts: variables at the top of `style.css`
- CV: replace `Noor_Ahmad_Faiz_Khan_CV.pdf` (keep the file name)
